🎓 School Management System (OOP + Graph)

This project is a simple School Management System developed using Python. It demonstrates Object-Oriented Programming (OOP) concepts like inheritance, method overriding, and constructor chaining. It also includes a graphical representation of data using Matplotlib.

🚀 Features
- Base class: "Person"
- Derived classes: "Teacher", "Student"
- Further derived class: "ClassTeacher"
- Demonstrates:
  - Inheritance
  - Method Overriding
  - Constructor Chaining
- Displays details of Teacher, Student, and Class Teacher
- Graph visualization (Age comparison using bar chart)

🛠️ Technologies Used
- Python
- Matplotlib (for graph visualization)

▶️ How to Run
1. Install required library:
pip install matplotlib
2. Run the Python file:
python project.py

📊 Output
- Displays details of Teacher, Student, and Class Teacher
- Shows a bar graph comparing ages

💡 Concepts Used
- Classes and Objects
- Inheritance
- Method Overriding
- Constructor Chaining
- Data Visualization
